# Prompt Bank

Copy-paste and make them yours. Replace anything in `[brackets]`. Start on **Auto**; drop to a lighter model (e.g. Claude Sonnet) for simple, high-volume work to save credits.

> **Rule of thumb:** a good Cowork prompt has a **Goal**, some **Context**, the **Sources** to use, and the **Format** you want back.

## ☀️ Start your day
```
Run my daily brief: what's on my calendar, the emails that need me, and my top 3 priorities.
```
```
What changed since yesterday across my email, Teams, and calendar? Just the things I need to act on.
```

## 📥 Inbox & email
```
Triage my unread mail by priority and separate "needs action from me" from newsletters.
```
```
Draft short replies to the emails that need a response. Flag anything that needs a decision instead.
```
```
Summarize the thread with [person] about [topic] and tell me where it stands.
```

## 📅 Meetings
```
Prep me for my [time] meeting: check the invite, pull attendee context, find related emails and docs, and give me a briefing.
```
```
Turn this meeting transcript into decisions, action items with owners, and follow-up emails.
```

## 🔎 Research & documents
```
Research [topic/3 competitors], write a one-page brief with sources, and build a 5-slide deck.
```
```
Read every document in [folder] and produce a summary with a citation map back to each source.
```
```
Take [document/deck] and turn the key points into a [1-pager / email / FAQ].
```

## 🗂️ Files & organization
```
Read the contracts in [folder] and table each vendor, renewal date, and auto-renew clause.
```
```
Analyze [OneDrive folder] and give me a structured catalog: what's here, duplicates, and what to archive.
```
```
Audit these documents against [our style guide] and list what's off-standard.
```

## 🧩 Skills (create & use)
```
Save this as a skill called "[name]". Trigger it when I say "[phrase]". Keep this exact format and rules.
```
```
[trigger phrase]   ← runs your saved skill
```
```
Show me my skills and what each one is triggered by.
```

## ⏰ Scheduled tasks
```
Every weekday at 8am, run my daily brief and send it to me.
```
```
Every Friday at 4pm, compile this week's [project] updates from Teams and email and post a status summary.
```

## 🌐 Browser use (Edge)
```
Find my recent receipts and start an expense report on [expense site], filling vendor, date, and amount.
```
```
Go to [portal], pull this week's [report] into a short summary, and paste it back to me.
```

## 💳 Cost & control
```
/cost
```
```
Before you send or post anything, show me a preview first.
```
```
Where did you save that? / Put the output in [folder].
```
```
Use [Claude Sonnet] for this one to keep it cheap.
```
