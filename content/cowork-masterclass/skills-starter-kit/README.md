# Skills Starter Kit

A **Skill** is a saved playbook — plain-language instructions Cowork loads on demand, so you stop re-prompting and cut credits.

## The fastest way to make one
1. Get a great result the manual way.
2. Say: `Save this as a skill called "[name]". Trigger it when I say "[phrase]".`
3. Test it in a fresh chat with your trigger phrase, then refine.

## Or author the file yourself
Copy [`SKILL-template.md`](./SKILL-template.md), fill it in, and upload it (or drop it in **OneDrive ▸ Documents ▸ Cowork ▸ skills ▸ your-skill-name ▸ SKILL.md**).

## What makes a skill *fire*
- A **precise name** in kebab-case (`weekly-status-report`).
- A **description with the exact trigger phrases** you'll actually say.
- **One scenario per skill** — split mega-skills.
