# Cowork Masterclass — source content

Original source material for the **Copilot Cowork Masterclass**, folded into `ai-with-april`
so this hub is the single home for April's learning content (previously its own repo,
`aprildunnam/copilot-cowork-masterclass`).

These are the raw markdown files the `resources/cowork-masterclass.html` page is built from —
kept here verbatim for provenance and portability, the same way `skill-framework-source.md` holds
the source text for the S.K.I.L.L. framework page. If you're editing the live page, edit
`resources/cowork-masterclass.html` directly; these files are the historical record, not a
build input.

- `source-readme.md` — the original repo's README
- `overview.md`, `glossary-and-faq.md`, `prompt-bank.md`, `resources.md` — original `docs/`
- `labs-and-challenges/` — the 4 challenges + 3 labs
- `skills-starter-kit/` — the SKILL template and two worked examples

Downloadable assets from the same source live in `assets/downloads/` (slide deck, cheat sheet PDF)
and `assets/img/` (cheat sheet PNG). Sample "Northwind Traders / Project Atlas" exercise data
(CSV/email fixtures for use in your own tenant) was intentionally not copied — it has no
standalone value as public content; the labs that reference it explain what each file is for.
