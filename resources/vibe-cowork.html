Delegating Real Work to Copilot Cowork

Stop prompting and start handing off. Follow the complete demo flow, download each reference file, and copy every prompt directly from this page. The session shows how to turn one successful Cowork task into an app, automation, skill, or plugin.

Presented at Vibe 2.0 September 21–23, 2026 · Salt Lake City Area, Utah ↗

The demo runbook

Work through these in order. Each demo includes its setup, reference files, exact prompt, and expected outcome.

1

Cowork 101: hand it your inbox

Delegate a real outcome instead of asking for one isolated summary.

Reference files

  • Complete Outlook demo mail

Demo flow

  1. Download the Outlook demo mail ZIP and import the EML files into a disposable demo mailbox.
  2. Keep the 15 festival messages unread and dated within the current week.
  3. Open Cowork, leave the model on Auto, and paste the prompt.
  4. Show the visible plan and let Cowork separate urgent work, quick replies, and noise.
  5. Pause on the approval step before any response is sent.
Go through my unread email from this week. Flag anything about Analog Fest that needs me, sort it into a short list by urgency, and draft replies to the quick ones. Show me the drafts before sending anything.

Expected result: Cowork should identify the sound quote, permit document, volunteer gaps, poster proofs, and press interview as actionable while separating newsletters and notices.

2

Prep a vendor meeting

Build one briefing from email, Teams, and an Excel order history.

Reference files

  • Crate & Needle email thread
  • Teams chat script
  • Vendor_Pipeline.xlsx
  • Fallback finished brief

Demo flow

  1. Import the synthetic Crate & Needle EML thread and post the supplied messages in a Teams chat.
  2. Upload Vendor_Pipeline.xlsx to OneDrive and create Analog Fest/Meetings.
  3. Create a 10:00 AM calendar meeting with Crate & Needle for the following day.
  4. Paste the prompt and watch Cowork gather context across the three sources.
  5. Review the preview before allowing it to create the Word briefing, then run /cost.
Prep me for tomorrow's 10am with Crate & Needle Records. Pull our last 6 months of email with them, the pop-up request, any Teams chats about them, and their past orders from Vendor_Pipeline.xlsx. Build a one-page Word briefing with 3 talking points and save it to /Analog Fest/Meetings/. Preview before you create anything.
/cost
3

Build a volunteer check-in app

Create a mobile app from a live SharePoint list without leaving Cowork.

Reference file

  • Volunteers.csv

Demo flow

  1. Create an Analog Fest SharePoint site and import Volunteers.csv as a list named Volunteers.
  2. Set the CheckedIn column to Yes/No.
  3. In Cowork, paste the /app prompt and answer its scoping questions.
  4. Preview and test the first version, then paste the refinement.
  5. Show how publishing hands the app into Copilot Studio for continued development.
/app Build an Analog Fest volunteer check-in app. Volunteers pick their name and shift and tap Check in. The shift lead sees who's checked in and who's missing for the current shift. Use the Volunteers list in the Analog Fest SharePoint site. Keep it simple and mobile-friendly.
Add a no-show count by shift at the top.
4

Create an event-triggered automation

Turn a repeatable inbox decision into a governed draft-and-approve workflow.

Reference files

  • Vendor_Pipeline.xlsx
  • PopUp_List.csv
  • Tape Hiss test email

Demo flow

  1. Import PopUp_List.csv into the Analog Fest SharePoint site and keep Vendor_Pipeline.xlsx in OneDrive.
  2. Paste the automation request in Cowork and keep its autonomy set to draft-and-approve.
  3. From a second mailbox, send the supplied Tape Hiss test email to the demo user.
  4. Show Cowork check the August 20 order, draft a “yes” response, and prepare the list update.
  5. Review each proposed action before approving it.
Whenever an indie label emails me asking about an Analog Fest pop-up table, summarize the request, check Vendor_Pipeline.xlsx for their past orders, draft a friendly reply (yes if they've ordered in the last 6 months, otherwise waitlist), and add them to the pop-up list. Draft everything and wait for my approval.
5

Turn a finished task into a shared skill

Start with a successful result, then capture the process as reusable instructions.

Reference file

  • Fallback vendor-brief skill

Demo flow

  1. Return to the completed Crate & Needle meeting-brief conversation from demo 2.
  2. Ask Cowork to save the successful workflow as a generalized skill.
  3. Inspect the generated SKILL.md and confirm the folder and skill names match.
  4. Start a fresh conversation and test the skill with Tape Hiss Records.
  5. Use the downloadable fallback only if live skill creation fails during rehearsal.
Save this as a skill called vendor-brief. Make it work for any vendor or label, not just Crate & Needle.
Prep me for my call with Tape Hiss Records.
6

Put a plugin to work

Send the same festival source into a connected visual-work tool.

Reference file

  • Fest_Plan.docx

Demo flow

  1. Upload Fest_Plan.docx to OneDrive and install the Miro plugin in the demo tenant.
  2. Paste the Miro prompt and show the connected plugin create a visual artifact.
  3. If Miro is unavailable, use the monday.com backup prompt instead.
Take Fest_Plan.docx and turn the three nights into a visual run of show in Miro: one frame per night, sets as cards in order, changeovers flagged in pink. Share the board with the shop manager.
Create a board for Analog Fest from Fest_Plan.docx with one group per night and a task per set.

The delegation model

PartWhat to specify
GoalThe outcome you want, not every click.
SourcesThe files, people, systems, or date range it should use.
FormatThe length, structure, tone, and destination.
BoundaryWhat it may do, what it must preview, and when it should ask.
